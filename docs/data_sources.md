# Open NASA & European Earth Observation Data Sources
## SURF Platform Data Grounding

| Indicator | Primary Sensor / System | Spatial Resolution | Temporal Resolution | Provider / Access Point |
|---|---|---|---|---|
| **Land Surface Temperature (LST)** | NASA Landsat 8/9 TIRS (Band 10) | 30m (resampled) | 16-day repeat | [USGS EarthExplorer](https://earthexplorer.usgs.gov/) / NASA LP DAAC |
| **Coarse Decadal Thermal Trend** | Terra/Aqua MODIS (MOD11A2) | 1,000m | 8-day composite | [NASA AppEEARS](https://appeears.earthdatacloud.nasa.gov/) |
| **Vegetation Health (NDVI)** | Copernicus Sentinel-2 MSI (B4, B8) | 10m | 5-day revisit | [Copernicus Open Access Hub](https://dataspace.copernicus.eu/) |
| **Decadal Canopy Baseline** | Terra MODIS (MOD13Q1) | 250m | 16-day composite | [NASA LP DAAC](https://lpdaac.usgs.gov/) |
| **Atmospheric & Solar Radiance** | AIRS & MERRA-2 Atmospheric Reanalysis | 0.5° x 0.625° | Daily / Monthly | [NASA Giovanni](https://giovanni.gsfc.nasa.gov/giovanni/) |
| **Multi-Sensor Area Extraction** | NASA AppEEARS | Native point/bbox | Dynamic query | [NASA EOSDIS](https://www.earthdata.nasa.gov/) |
| **High-Resolution Demographics** | WorldPop Gridded Population (100m) | 100m constrained | Annual benchmark | [WorldPop / University of Southampton](https://www.worldpop.org/) |
| **Deltaic Topography & Elevation** | NASA NASADEM / SRTM | 30m | Static benchmark | [NASA Earthdata](https://earthdata.nasa.gov/) |
