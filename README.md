# SURF — Satellite Urban Resilience Framework

SURF is a NASA Space Apps Challenge prototype that transforms satellite observations into urban climate insights.

## Features
- Urban heat risk visualization
- Vegetation health analysis (NDVI concept)
- Urban change analysis framework
- Interactive map dashboard prototype

## Workflow

Satellite Data → Processing → Environmental Indicators → Interactive Visualization → Recommendations

## NASA Data Sources
- Landsat
- MODIS
- NASA Giovanni
- NASA AppEEARS

## Tech Stack
Backend:
- Python
- FastAPI

Frontend:
- HTML
- CSS
- JavaScript
- Leaflet Map
